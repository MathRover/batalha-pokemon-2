Batalha Pokémon

Um projeto de simulação de batalha Pokémon desenvolvido com Python, HTML, CSS e Jinja. O projeto permite criar batalhas interativas entre Pokémon, mostrando ataques, pontos de vida e resultados em tempo real em uma interface web simples e funcional.

Tecnologias utilizadas

Python – Lógica da batalha, controle de ataques e pontos de vida.

HTML / CSS – Estrutura e estilo da interface web.

Jinja – Renderização dinâmica de páginas HTML com dados do Python.

[Outro framework] – (adicionar aqui se lembrar).

Funcionalidades

Seleção de Pokémon para batalhar.

Sistema de turnos com ataques e defesa.

Cálculo de pontos de vida e vitória.

Interface web interativa e responsiva.

Histórico de ataques exibido na página.

Como rodar o projeto

Clone o repositório:

git clone https://github.com/MathRover/batalha-pokemon-2.git


Entre na pasta do projeto:

cd batalha-pokemon-2


Instale as dependências (se houver um requirements.txt):

pip install -r requirements.txt


Rode o projeto:

python nome_do_arquivo_principal.py


Abra o navegador e acesse:

http://localhost:5000


(ou a porta configurada no seu projeto)

Como contribuir

Faça um fork do projeto.

Crie uma branch com sua funcionalidade:

git checkout -b minha-nova-funcionalidade


Faça commit das alterações:

git commit -m "Adiciona nova funcionalidade"


Envie para o repositório remoto:

git push origin minha-nova-funcionalidade


Abra um Pull Request.
